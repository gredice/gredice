# App access for the closed test

No test account is required for the Android Auto fixture.

1. Install the closed-test build on an Android phone.
2. Connect Android Auto or start the Desktop Head Unit.
3. Open **Gredice Dostava** in the car launcher.
4. Confirm that two synthetic Zagreb stops are visible.
5. Select either stop and confirm that the default navigation app receives the location.

The phone launcher opens the existing Delivery web app, which can show its normal sign-in screen. The category-feasibility flow itself does not require that sign-in. No mock location, purchase, booking, or delivery mutation is required.
