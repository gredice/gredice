# Original Kestenijada checkpoint evidence

These nine files are preserved byte-for-byte from implementation commit
`d0fee5e13a2230d160c723a4ea65e52d1c285d83`, before the #4992 integration rebase.
The archived evidence record retains its original repository-relative paths:
its source hashes refer to that original commit; its PNG/geometry hashes can be
checked against the matching filenames in this directory. They are provenance,
not claims that the original source hashes match the new stack.

Fresh captures and current source bindings live in the parent directory.
Astra's original scene review remains attached to this numerical composition;
new pixel hashes are separately recorded after integration. Renderer counters
remain diagnostic samples only.
